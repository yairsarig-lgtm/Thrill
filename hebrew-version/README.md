# Thrill עברית (גרסת בודקים)

גרסה עברית מלאה של Thrill v0.19, לבודקים בלבד. היא אינה חלק מהגרסה הראשית.

- אפליקציה נפרדת (`com.freewill.predict.he`), כך שאפשר להתקין אותה לצד הגרסה הרגילה.
- המקלדת מופיעה בשם **Thrill עברית**, בפריסה עברית רגילה עם מקש ABC למעבר לאנגלית.
- כל הממשק בעברית ומימין לשמאל, בגופן Frank Ruhl Libre. תרשים השולחן נשאר בכיוון הפיזי שלו.
- כל שש הרוטינות ו"בנו בעצמכם", עם טקסטים ודוגמאות בעברית.
- מקלידים שם ואחריו מספר רוטינה: `נועה` או `נועה1` = רוטינה I, `נועה4` = הטלת קובייה.

## תגיות בטקסט החיזוי

| תגית | משמעות |
|---|---|
| `{צופה}` | השם שמקלידים במקלדת |
| `{קוסם}` | השם שלכם |
| `{חפץ הצופה}` / `{חפץ הקוסם}` / `{חפץ נותר}` | החשיפה הרגילה וחשיפת המומחה |
| `{חפץ}` / `{חפץ מוצבע}` | השמונה |
| `{מספר}` | הטלת קובייה |
| `{סמל}` | סמלי ESP |
| `{הטלה 1}` `{הטלה 2}` `{הטלה 3}` | הטלות מטבע |
| `{תוצאה}` | רוטינות שבניתם בעצמכם |

## עדכון ובנייה

הקוד בתיקייה הזו נוצר מהגרסה הראשית. אחרי שינוי בגרסה הראשית:

```
python3 translate.py   # מעתיק את src, res, assets ומתרגם
./build.sh             # בונה ThrillHebrew.apk
```

אם טקסט באנגלית השתנה, `translate.py` עוצר ומציין איזה.
