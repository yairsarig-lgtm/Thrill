# Thrill עברית (גרסת בודקים)

גרסה עברית מלאה של Thrill, לבודקים בלבד. היא אינה חלק מהגרסה הראשית.

- אפליקציה נפרדת (`com.freewill.predict.he`), כך שאפשר להתקין אותה לצד הגרסה הרגילה.
- המקלדת מופיעה בשם **Thrill עברית**, בפריסה עברית רגילה עם מקש ABC למעבר לאנגלית.
- כל הממשק בעברית ומימין לשמאל.

## תגיות בטקסט החיזוי

- `{צופה}` – השם שמקלידים במקלדת
- `{קוסם}` – השם שלכם
- `{חפץ הצופה}` – החפץ שנשאר אצל הצופה
- `{חפץ הקוסם}` – החפץ שנשאר אצלכם
- `{חפץ נותר}` – החפץ שנשאר בצד

## בנייה

מתוך התיקייה הזו: `./build.sh` (אותם כלים כמו בגרסה הראשית). הקובץ שנוצר: `ThrillHebrew.apk`.
